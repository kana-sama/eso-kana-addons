# Kana Character Knowledge: scribing sources

Надстройка Character Knowledge помогает найти недостающие страницы чарописи.

- Для каждой страницы из ежедневных наград показывает три отдельных значка: занятие в DLC-зоне, гильдия и PvP.
- При наведении на значок слева появляется короткая подсказка: что сделать и где взять задание.
- Делает значок полупрозрачным, если выбранный персонаж сегодня уже получил страницу за это занятие. После ежедневного сброса значок снова становится ярким.
- В подсказке также сообщает, если страницу за это занятие сегодня получал другой персонаж аккаунта.
- Позволяет исправить отметку конкретного занятия через ПКМ по его значку.
- Сохраняет штатные значки особых страниц из квестов и залов Гильдии магов.
- Добавляет слева от поиска в «Чарописи» галочку «Скрывать известные»: она скрывает страницы и гримуары, изученные выбранным персонажем, и работает вместе с поиском.
- В собственных настройках отдельно отключаются подсказки источников и дневной учёт.
- Состояние фильтра известных сохраняется; его также можно изменить в собственных настройках без перезагрузки интерфейса.

«Не зафиксировано» означает, что аддон не наблюдал получение: награда могла быть
получена до установки или при выключенном учёте. Сдача квеста, просмотр коробки,
покупка страницы и перенос из банка не ставят отметку получения за занятие.
