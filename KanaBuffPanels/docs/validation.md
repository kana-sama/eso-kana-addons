# Проверки Kana Buff Panels

Дата: 2026-10-18. ESO API 101051. Реализация проверена локально; клиент ESO и профайлер пока не использовались.

## Автоматические проверки

Раннер использует `lupa.lua51` версии 2.8, а не системную Lua 5.4. Наборы изолированы. Проверяются реальные Rules, Layout, TimerLayout, Native, Panels, Menu, Settings и Core; подменена только внешняя граница ESO/HUD/LAM/LibCustomMenu.

Команды из корня репозитория:

```sh
python3 -m pip install --target /private/tmp/kana-buff-panels-test-deps -r KanaBuffPanels/tests/requirements.txt
python3 KanaBuffPanels/tests/run.py --all
python3 KanaBuffPanels/tests/run.py --syntax
```

Локальный итог: **60 passed, 0 failed**; синтаксис **18 Lua-файлов** — 0 ошибок; добавленные строки полного изменения `jj diff --git` — 0 ошибок пробелов. Все команды завершились с кодом 0.

Проверяемые условия: идентичность заимствованных контролов и их членство в штатном пуле; порядок и повторяющиеся экземпляры; очистка признака владения до переиспользования для цели; компактная исходная панель; неподвижная опора раскладки; запас для двух строк Duration; поздняя загрузка сохранений HUD; раздельные режимы клавиатуры/геймпада; идентификатор эффекта в открытом меню; поиск и восстановление неактивного эффекта; однократная инициализация и возврат к штатному UI при ошибке.

В стенде `GetNumBuffs`, `GetUnitBuffInfo` и `RegisterForUpdate` завершаются ошибкой. На 120 штатных тиках не вызывается новая раскладка и не создаются контролы. При перестройке каждый активный эффект классифицируется один раз независимо от числа панелей. Это проверка структуры работы, а не измерение FPS.

Независимое ревью обнаружило одну ошибку обновления рамки уже открытого HUD editor при изменении числа эффектов. Исправлена синхронизацией размеров зарегистрированного контрола при сохранении его CENTER-якоря; регрессионный тест сначала воспроизвёл ошибку, затем прошёл. Других конкретных замечаний ревью не выявило.

Регрессия ESO Plus: `artificial:0` принимается при открытии меню, назначении панели, скрытии и повторной загрузке сохранений. Обычный `ability:0` остаётся недопустимым. До исправления воспроизведено отсутствие меню; после исправления проходят весь цикл и проверка сохранений.

Регрессия пустой панели: её рамка в редакторе вытянута вдоль выбранной оси при всех трёх направлениях роста, а опорная точка остаётся неподвижной. Рамка занимает место трёх иконок, но сами иконки не создаются; геометрия непустой панели не меняется. Проверены оба режима ввода и разные размеры шрифта.

Регрессия отступа бокового таймера: короткий текст центрировался в подписи шириной с иконку. Теперь слева текст выровнен вправо, справа — влево, к ближайшему краю иконки; зазор между подписью и иконкой остаётся 5 единиц UI. Проверены обе ориентации панели, центрирование внутри иконки и восстановление исходного выравнивания при возврате вниз, скрытии, аварийном отключении, постоянном эффекте и переиспользовании пула. До исправления два новых теста падали.

Регрессия сдвига панели при переносе эффекта с таймером: режим «От центра» центрировал всю рамку по двум осям, включая подпись. Теперь центрирование действует только вдоль направления роста: X всех иконок колонки и Y всех иконок строки совпадают с опорой панели независимо от таймера. Рамка по-прежнему охватывает подписи, а расчёт промежутков вдоль панели предотвращает наложение. Проверены все положения таймера и направления роста, размеры иконок 40/46, низкие и высокие подписи; отдельный тест проверяет неизменность расстояния иконок до края экрана при добавлении, перестановке и удалении временного эффекта. До исправления три проверки падали.

## Уточнение интеграции

Размещение таймера: перемещается исходный Duration label; его текст, шрифт, видимость и обновление остаются штатными. Место под подпись учитывается только для эффекта с `duration > 0` и без `permanent`, как в [штатном UpdateDuration](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/buffdebuff/buffdebuffstyles.lua#L133). Тесты проверяют постоянные и смешанные эффекты при четырёх положениях таймера и шести вариантах роста, сохранение настройки HUD, а также восстановление исходных якорей/ширины подписи при скрытии, возврате, удалении панели, аварийном отключении и переиспользовании иконки для цели. Схема SavedVariables не менялась.

Помимо выдачи/сброса метапулов и Update адаптер дополняет **экземпляр** `RefreshContainerVisibility`. Один общий родитель новых панелей повторяет результат штатной видимости двух групп. Это сохраняет скрытие при открытии колеса быстрого доступа без обхода панелей на кадре. Сам `OnUpdate`, события эффектов, таймеры, sourcePool и классы ESO не меняются.

Проверены закреплённые источники [buffdebuff.lua](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/buffdebuff/buffdebuff.lua), [buffdebuff.xml](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/buffdebuff/buffdebuff.xml), [HUD manager](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/hud/hudmanager.lua) и [метапул](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/libraries/zo_templates/objectpooltemplates.lua). Контракты LAM и LibCustomMenu сверены с установленными библиотеками.

## Проверка в ESO — не выполнена

После включения аддона и одного `/reloadui`:

- Создать две панели, разместить пустую; проверить ПКМ, перенос, скрытие, поиск, возврат, переименование и удаление.
- Проверить все шесть вариантов роста, чётное/нечётное число иконок, высокие подписи, масштаб и небольшое окно настроек. Убедиться, что последние элементы длинных списков доступны прокруткой.
- Проверить четыре положения таймера на постоянных и временных бафах, отсутствие лишнего отступа у постоянных и возврат подписи вниз на стандартной панели и у цели.
- При росте от центра добавить и убрать временный баф: расстояние колонки до правого края и строки до нижнего края должно сохраняться при каждом положении таймера.
- Проверить таймеры, стаки, мигание, истечение эффекта, эффект цели после переиспользования пула, штатную автоматическую видимость, колесо быстрого доступа и смену HUD-сцен.
- Проверить клавиатуру/геймпад; затем повторить `/reloadui` один раз для проверки сохранения названий, назначений, ориентации и позиции.

Локальные моки не подтверждают фактическую отрисовку, приватность API или совместимость с другим buff UI.

## Нагрузка — не измерена в клиенте

Нужны одинаковые условия со штатным UI и с аддоном: одна сцена и набор эффектов, стабильный размер окна, одинаковые другие аддоны. Сравнить время функций, аллокации и время кадра при массовом обновлении эффектов; проверить отсутствие роста контролов/хуков после повторной выдачи пула. До такого измерения ускорение и конкретный FPS не заявляются.
