# Как пользоваться

Нужны LibAddonMenu-2.0 и LibCustomMenu. Аддон рассчитан на ESO API 101051.

1. В меню настроек дополнений откройте **Kana Buff Panels**. Создайте панель, задав ей имя.
2. В режиме курсора нажмите ПКМ по штатной иконке эффекта своего персонажа. Выберите **Переместить на панель** и нужное имя. **Стандартная** возвращает эффект на обычную панель.
3. В штатном редакторе интерфейса выберите созданную панель. Там доступны положение, **Ориентация** и **Рост**: строка вправо/влево/от центра или колонка вниз/вверх/от центра. В пункте **Таймер** выберите **Снизу**, **Слева**, **Справа** или **Внутри**. Пустые панели тоже доступны для размещения.
4. **Скрыть** в меню эффекта добавляет его в чёрный список. В настройках дополнения найдите запись по имени или ID и нажмите **Показать**. Прежнее назначение панели сохраняется.

В настройках дополнения у панели меняется только имя. После её удаления назначенные ей эффекты возвращаются на стандартную; скрытые остаются скрытыми. Эффекты с одинаковым названием различаются по ID.

Бафы без таймера стоят с обычным небольшим промежутком. Для временных эффектов место резервируется только там, где видна подпись. Чтобы уплотнить колонку, расположите таймер слева, справа или внутри иконки. По умолчанию он остаётся снизу.

Появление таймера не сдвигает линию иконок: у колонки сохраняется общий X, у строки — общий Y, в том числе при росте от центра.

Панели используют штатные настройки видимости эффектов ESO, включая показ в бою, длительные и постоянные эффекты. Аддон не включает их автоматически. Эффекты цели под прицелом не затрагиваются. Имена, назначения и чёрный список общие для аккаунта; расположение и параметры раскладки сохраняет штатный редактор отдельно для клавиатуры и геймпада.

Аддон использует существующие иконки ESO. Одновременная работа с аддонами, которые заменяют или перестраивают эту же систему эффектов, не проверена. При обнаружении несовместимого API аддон сообщает причину и оставляет штатное отображение.
