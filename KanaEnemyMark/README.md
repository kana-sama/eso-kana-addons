# KanaEnemyMark

Standalone enemy markers extracted from the locally installed FancyActionBar+ 2.19.7.
Red arrows mark enemies you are fighting, using ESO's native aggro markers.
Enabled by default; default size 26, configurable from 10 to 90 in addon settings.
Enabling/disabling requires a UI reload. Settings are account-wide.
Requires LibAddonMenu-2.0; FancyActionBar+ is not required.
Disable FancyActionBar+'s Enemy Markers option if using both addons, because
both configure the same global ESO aggro marker.

The marker API calls and texture/redarrow.dds come from FancyActionBar+.
Original authors: Incanus, dack_janiels, nogetrandom, andy.s.
