# KanaInfoBar

Компактная панель ESO без фона: иконки и текст с обводкой, несколько строк,
перетаскивание виджетов и сохранение настроек на аккаунт.

Все семь значков используют собственные монохромные текстуры с одинаковым
максимальным видимым размером. SVG-исходники находятся в `textures/`;
`textures/build.cjs` обрезает прозрачные поля, центрирует рисунки и собирает DDS
(Node.js + sharp). Числа имеют оптическую поправку по вертикали для BOLD_FONT.

## Запуск

Включить KanaInfoBar в списке аддонов и выполнить `/reloadui`.

- `/kanainfobar` — настройки через LibAddonMenu-2.0.
- `/kanainfobar edit` — редактор, доступный даже при скрытых виджетах.
- ПКМ по виджету — меню редактора и настроек.

В редакторе перетаскивай виджеты внутри строки, между строками или в зону
«+ Новая строка». Область «Не используются» отключает виджет; перенос обратно
в строку включает его. Нулевые/недоступные показатели видны с пометкой «скрыт».
Ручка «Переместить панель» перемещает всю панель.

«Готово» сохраняет изменения; «Отмена» возвращает состояние до открытия редактора.
Esc отменяет текущий перенос, затем закрывает редактор без сохранения.
Смена сцены также отменяет незавершённое редактирование.

## Якорь

Восемь вариантов — углы и середины сторон самой панели. Положение задаётся
перетаскиванием, якорь задаёт направление роста и выравнивание строк.
Левые якоря выравнивают строки влево, правые — вправо, середина верхней/нижней
стороны — по центру. При смене якоря панель сохраняет свою позицию.
Для размещения под компасом удобно выбрать середину верхней стороны.

В настройках есть **Grid mode**. При включении строки используют общие столбцы:
ширина каждого столбца равна ширине самого широкого виджета в нём. Короткие
строки занимают левые, правые или средние столбцы согласно выбранному якорю.
Скрытые показатели не оставляют пустых ячеек. По умолчанию режим выключен;
переключение не меняет состав строк и сохраняется после `/reloadui`.

## Показатели

| Виджет | Данные | ЛКМ |
| --- | --- | --- |
| DPS | Свой DPS из Combat Metrics: `842`, `5.6k`, `42k`; доля в процентах только в группе. Последний результат сохраняется до следующего боя | Combat Metrics |
| Сообщения | Счётчик непрочитанных AetherChat с его настройками уведомлений | AetherChat |
| Пинг | Миллисекунды; >150 оранжевый, >200 красный | — |
| FPS | Кадры в секунду | — |
| Инвентарь | Занято/вместимость; от 80% оранжевый, от 95% красный | Рюкзак |
| Прочность снаряжения | Минимальная прочность надетой вещи с износом. В подсказке — средняя прочность и цена починки всех надетых вещей; при ≤20% оранжевый (примерно две PvE-смерти), при 0% красный | — |
| Краденые сокровища | На панели — общая сумма (`880g`). В подсказке — сколько можно продать сегодня, если выбрать самые дорогие сокровища с учётом оставшейся квоты скупщика. Включены стопки, хлам и бонусы цены | Все краденые вещи в рюкзаке |

Сообщения и сокровища скрываются, когда их нет. Пустые строки временно схлопываются,
но сохраняют состав. Изменения чисел не переносят виджеты в другие строки.
Ширина резервируется с запасом и шагом 16 UI px; сужение допускается после
30 секунд при уменьшении хотя бы на два шага. Точный показатель и действие
доступны в подсказке.

Фильтр краденого виден в заголовке инвентаря; кнопка «Показать все вещи» снимает
его. Смена категории и закрытие инвентаря также снимают фильтр. Переключение
на банк/торговлю не оставляет фильтр в этих окнах. Клик по обычной сумке открывает
рюкзак без фильтра KanaInfoBar.

## Зависимости и расширение

Требуется LibAddonMenu-2.0. Combat Metrics и AetherChat необязательны: при отсутствии
CM будет прочерк, при отсутствии AC виджет сообщений скрывается. Остальные
показатели продолжают работать. Аддон рассчитан на интерфейс клавиатуры/мыши ESO.

Исходники Combat Metrics, AetherChat и других аддонов не изменяются.

Новый показатель регистрируется через `KanaInfoBar:RegisterWidget`:

```lua
KanaInfoBar:RegisterWidget({
    id = "my_metric", -- уникальный стабильный id
    name = "Мой показатель",
    icon = "/esoui/art/inventory/inventory_stolenitem_icon.dds",
    sample = "999", -- резерв ширины
    read = function()
        return {text = "42", visible = true, detail = "Пояснение",
                color = "normal", clickable = true}
    end,
    action = function() -- необязательно
        -- открыть связанное окно
    end,
    clickHint = "ЛКМ — открыть",
})
```

Доступные цвета: `normal`, `orange`, `red`, `gold`. Обновление — четыре раза
в секунду; дорогостоящие вычисления следует обновлять по событиям и возвращать
из `read` готовые значения. Новые виджеты доступны в редакторе; для отображения
переключателя в LAM регистрировать их до инициализации настроек аддона.

## Проверка

Из каталога AddOns:

```sh
lua KanaInfoBar/tests/test_logic.lua
lua KanaInfoBar/tests/test_providers.lua
lua KanaInfoBar/tests/test_inventory.lua
lua KanaInfoBar/tests/test_ui.lua
luac -p KanaInfoBar/*.lua
```

Проверка повторных загрузок с настоящей библиотекой SavedVariables ESO:

```sh
lua KanaInfoBar/tests/test_savedvars.lua /path/to/esoui/libraries/utility/zo_savedvars.lua
```

Она проверяет, что рекурсивное добавление значений по умолчанию не возвращает
перенесённые виджеты в первую строку.

Эти проверки выполняют реальную логику аддона с подставленными границами ESO API.
Они не доказывают работу движка интерфейса. В игре требуется проверить реальные
иконки/обводку, читаемость на светлом фоне, перетаскивание и Esc, края экрана,
подсказки, все четыре действия по клику и совпадение данных с CM/AC/скупщиком.
