# Группы эффектов и обновления

Проверено 3 октября 2026 по исходному коду. Выводы для проектирования, не замеры производительности.

## Штатный интерфейс ESO

[esoui/esoui, buffdebuffstyles.lua, строки 1–60](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/buffdebuff/buffdebuffstyles.lua#L1): граница длительного эффекта 60 секунд; `IsVisible` проверяет permanent отдельно, затем полную `timeEnding - timeStarted`, длительный при `>= 60`. Также различаются бафы/дебафы, игрок/цель, собственные/чужие применения. Это полезные независимые признаки для фильтра, но не семантическая категория «еда».

[buffdebuff.lua, 56–137](https://github.com/esoui/esoui/blob/6639eb2adecc0480557d9068579319919a0c3fe6/esoui/ingame/buffdebuff/buffdebuff.lua#L56): события помечают контейнер dirty, фильтр EVENT_EFFECT_CHANGED по unit tag; используются ZO_MetaPool, при Update освобождаются контролы и перестраивается содержимое. Для KanaEffects предлагаем более узкое обновление затронутых ячеек. Это собственное проектное решение, не установленное преимущество в FPS.

## Srendarr

[Defaults.lua](https://github.com/DakJaniels/Srendarr_ESO/blob/92769505d8431d938655ec59e1f9951d686d7f04/Srendarr/Defaults.lua): отдельные группы коротких/долгих, переключаемых, пассивных, дебафов, наземных, Major, Minor, зачарований, эффектов цели. В локальной установленной копии те же группы; shortBuffThreshold=60, AURA_UPDATE_RATE=0.05.

[AuraControl.lua, 228–258](https://github.com/DakJaniels/Srendarr_ESO/blob/92769505d8431d938655ec59e1f9951d686d7f04/Srendarr/AuraControl.lua#L228): классификация игрока отделяет именованные уровни/пассивные/переключаемые/зачарования, затем проверяет полную длительность против shortBuffThreshold; долгий при строгом `>`. Следовательно граница ровно 60 секунд различается со стоком. В нашем проекте явно выбираем семантику стока: `< 60` и `>= 60`, без щели/пересечения.

[Aura.lua, 225–302](https://github.com/DakJaniels/Srendarr_ESO/blob/92769505d8431d938655ec59e1f9951d686d7f04/Srendarr/Aura.lua#L225): один OnUpdate с ограничением частоты проходит activeTimedAuras. [822–829](https://github.com/DakJaniels/Srendarr_ESO/blob/92769505d8431d938655ec59e1f9951d686d7f04/Srendarr/Aura.lua#L822): Release скрывает ауру и убирает из таблиц таймера/lookup. [AuraControl.lua, 2023–2094](https://github.com/DakJaniels/Srendarr_ESO/blob/92769505d8431d938655ec59e1f9951d686d7f04/Srendarr/AuraControl.lua#L2023): отдельные combat-event подписки фильтруются по ability ID.

Берём принципы общей обработки времени, фильтрованных событий и переиспользования UI. В KanaEffects предлагаем менять SetText только при изменении строки, а состав/геометрию — при изменении данных. Не утверждаем, что Srendarr везде избегает лишних SetText: в указанном цикле он вызывает SetText при обновлении активной ауры.

## Bandits User Interface

[BUI_Buffs.lua, 1–45](https://github.com/secretrob/BanditsUserInterface/blob/00d415ce95a63a3dc53977d81ca1a91a363e47b7/BUI_Buffs.lua#L1): отдельные списки Passives и buffFood; пищевые ID добавляются в пассивную группу. [1051–1078](https://github.com/secretrob/BanditsUserInterface/blob/00d415ce95a63a3dc53977d81ca1a91a363e47b7/BUI_Buffs.lua#L1051): признак passive зависит от нулевой длительности или каталога Passives с исключением Active; пассивы могут отправляться в дополнительную панель.

Полезен сам подход: еда относится к обслуживающей группе по смыслу, даже если технически это конечный таймер. Для нашего каталога сохраняем исходную длительность и семантические теги отдельно, чтобы не называть еду реально бессрочной.

## Наше решение

Сравнивались три варианта: один победивший виджет по приоритету; только независимые фильтры; переиспользуемые наборы с явными исключениями. Первый противоречит подтверждённому требованию дублирования. Второй требует вручную синхронизировать отрицания сложных правил. Выбран третий: независимые виджеты, включение A и исключение B, готовая кнопка «Разделить с набором…».

Категоризация по полному времени применения не переносит еду в боевую панель на последних секундах. Именованность, положительность, длительность и семантика еды — разные признаки, а не одна взаимно исключающая колонка. Настраиваемый набор соединяет их для конкретного сценария. Длительные опасные дебафы по умолчанию сохраняются среди боевых.

Эти правила и бюджеты производительности пока проектные. Ни HTML, ни просмотр чужого кода не доказывают нагрузку будущего Lua-аддона.
