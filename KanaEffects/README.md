# KanaEffects

Конструктор компактных панелей эффектов для ESO. Произвольные фиксированные таблицы и растущие гриды, пары Minor/Major, переиспользуемые наборы и явные исключения между ними.

Рабочий Lua-аддон в общем репозитории `eso-kana-addons`. Редактор открывается командой `/ke`. После изменения файлов выполните `/reloadui`.

- [Проверка наличия эффекта на панели](docs/panel-references.md) — `on_panel`, ошибки ссылок и переименование.
- [Интерактивный редактор-макет](docs/mockups/index.html) — перемещение, таблицы, правила, якоря, общий выбор эффектов, Save/Cancel.
- [План реализации для субагентов](docs/superpowers/plans/2026-10-03-kana-effects-implementation.md) — 16 заданий, зависимости, владение файлами и приёмка.
- [Контракты модулей](docs/superpowers/plans/2026-10-03-kana-effects-contracts.md) — общие типы, API и команды редактора.
- [Спецификация v2](docs/SPEC.md) — требования и точные правила работы.
- [Наборы и производительность: источники](docs/research/widgets-and-sets.md).
- [Первичное исследование аналогов](docs/research/findings.md).
- [Фактическая проверка](docs/research/validation.md).

HTML — дизайн-прототип с демонстрационными состояниями и условными значками. Не подключён к ESO. Масштаб и настоящие текстуры требуют приёмки в игре. Предыдущая жёсткая раскладка четырёх панелей заменена конструктором; её история сохранена в Git.

Локальный просмотр: `python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/mockups`.
