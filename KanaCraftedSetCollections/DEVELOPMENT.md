# KanaCraftedSetCollections

Надстройка показывает крафтовые сеты в штатной клавиатурной вкладке **Коллекция сетов** ESO. Нужна установленная и включённая **LibSets**. Собственной базы сетов, настроек и SavedVariables нет.

Крафтовые сеты добавляются в существующие категории локаций. Сеты без подходящей категории находятся в «Других местах крафта». Поиск по названию работает через обычное поле коллекции. У каждого сета одна цветная карточка предмета: она показывает бонусы в обычной подсказке и не предлагает реконструкцию. Под названием сета отдельной строкой показано, сколько изученных особенностей требуется для изготовления. Полоса прогресса, стоимость реконструкции и кнопка карты у крафтовых сетов скрыты.

Число требуемых изученных особенностей берётся из LibSets. Цветная карточка служит только справочной отметкой: она не добавляет предмет в игровую коллекцию. Штатные счётчики собранности остаются прежними. На станции трансмутации крафтовые записи скрыты.

Поддерживается интерфейс клавиатуры на PC/Mac. Проверка в запущенной игре после установки: открыть «Коллекция сетов», найти крафтовый сет по названию, проверить полную строку требований и бонусы в подсказке.
