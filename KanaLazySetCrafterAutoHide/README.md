# Kana Lazy Set Crafter Auto Hide

Надстройка для **Dolgubon's Lazy Set Crafter**:

- При открытии станка окно видно, если в общей очереди есть предметы.
- С пустой очередью окно изначально скрыто.
- Внизу, рядом со штатными действиями станка, появляется кнопка
  **«Показать Set Crafter» / «Скрыть Set Crafter»**.
- Кнопка работает при любой очереди. Крестик, команды `/dsc`, `/dlsc`,
  `/setcrafter` и горячая клавиша исходного аддона продолжают работать.
- Очистка очереди, смена вкладки и повторные события того же станка
  не меняют выбранную вручную видимость. При следующем входе начальное
  состояние снова определяется очередью.

Поддерживает кузницу, портняжный, столярный, ювелирный станки и зачарование.
Учитывает всю очередь, даже если предметы предназначены для другого станка.
Кнопка использует уже существующее назначение «Открыть/закрыть окно
Set Crafter»; её можно нажать мышью без назначения клавиши.

Зависимость: `DolgubonsLazySetCrafter` **3.0.8.0+**. Собственных настроек нет.
Настройка автопоказа исходного аддона уступает правилу очереди. Настройки
автокрафта, закрытия при выходе и постоянного плавающего значка сохраняются.
Файлы исходного аддона и его SavedVariables надстройка не изменяет.

## Проверка

Локально: `lua KanaLazySetCrafterAutoHide/tests/test.lua` из корня репозитория.
Тесты проверяют логику и интеграционные контракты через Lua-стенд;
отрисовку, ввод и реальный крафт подтверждает клиент ESO.

Для дополнительной проверки с загрузкой исходного обработчика установленного
Set Crafter: `DLSC_SOURCE=../DolgubonsLazySetCrafter/SetCrafter.lua lua KanaLazySetCrafterAutoHide/tests/test.lua`.

Включить оба аддона и один раз выполнить `/reloadui`. Затем:

1. Войти на станок с пустой очередью: окно скрыто, кнопка снизу доступна.
2. Несколько раз показать и скрыть окно кнопкой, затем закрыть крестиком
   и открыть снова. Проверить существующую горячую клавишу, если назначена.
3. Добавить предмет в очередь, выйти и снова войти: окно открыто.
   Скрыть вручную, сменить вкладку/выбранный сет: окно остаётся скрытым.
4. Открыть окно и очистить очередь: оно остаётся открытым до ручного
   закрытия или выхода; следующий вход начнётся со скрытого окна.
5. Убедиться, что «Выйти», «Переработать» и остальные действия работают,
   а новая кнопка исчезает после ухода со станка.
6. Проверить длинную очередь, её прокрутку, последнюю строку и меньшую
   высоту окна/масштаб UI. В режиме геймпада проверить переходы между
   меню станка и отдельными операциями; клавиша берётся из настроек Set Crafter.
