# Kana LeadList: search tools

Надстройка LeadList:

- Добавляет фильтры зацепок для первой раскопки и обычных наград.
- Показывает конечную награду древности в подсказке.
- Запускает лоцирование двойным щелчком по зацепке.
- Позволяет выбирать видимые столбцы списка и подстраивает их ширину.
- Подсвечивает зацепки текущей зоны.
- Исправляет сортировку по зонам.
