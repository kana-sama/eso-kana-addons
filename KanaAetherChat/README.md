# Kana AetherChat Patch

- Активирует строку ввода при открытии AetherChat.
- Закрывает окно клавишей Escape.
- Исправляет закрытие окна после других действий.
- Закрывает чат после выполнения команды.
- Сохраняет выбранный канал между сеансами.
- Не сбрасывает прокрутку к новым сообщениям, пока вы читаете старые.
- Показывает каналы гильдий в списке чатов.
- Исправляет отображение строки ввода.
- Возвращает штатный чат ESO на место после закрытия AetherChat.
- Исправляет появление окна AetherChat.
- Позволяет скрыть плавающий значок AetherChat.
- Позволяет включить компактный вид штатного чата ESO.

- Каждую правку можно включить или отключить в настройках Kana AetherChat Patch.
