# KanaSkillExp

Надстройка над **SkillExp 1.1.0**. Оба аддона должны быть включены.
Исходные файлы SkillExp не изменяются.

- В окне навыков нажмите ПКМ по значку умения или названию ветки.
- Выберите «Добавить в SkillExp» / «Удалить из SkillExp» в контекстном меню.
- Удалять также можно через контекстное меню строки самого трекера.
- `/skillexp` и прежняя горячая клавиша SkillExp показывают/скрывают список.

По умолчанию сохраняются обычный список SkillExp и все его настройки.
Выбранные вручную элементы отображаются дополнительным списком под ним.
В `/skillexp config` добавлен переключатель **«Только выбранные навыки»**:
он позволяет показывать только ручной список. Переключение не сбрасывает
ни старые настройки, ни выбранные элементы.

Ручной список изначально пустой. Выбор и порядок добавления сохраняются для персонажа.
Умения и ветки идут в одном списке; повторно добавленный после удаления элемент
попадает в конец. Морф отслеживается как то же умение. Максимально прокачанные
и временно недоступные элементы остаются на своих местах. Пассивные умения
показывают приобретённые ранги, поскольку отдельного опыта у них нет.

Надстройка использует положение, видимость и настройку процентов SkillExp.
Все старые опции продолжают управлять обычным списком SkillExp. Настройка
процентов действует также на ручной список; ручной список сохраняет выбранные
строки, в том числе максимально прокачанные. При выключенной опции «Только
выбранные навыки» перемещать весь трекер нужно за обычное окно SkillExp.
После отключения KanaSkillExp и `/reloadui` остаётся обычное поведение SkillExp.

Контекстное меню предназначено для интерфейса клавиатуры и мыши.

## Проверки

Из каталога AddOns:

```sh
lua KanaSkillExp/tests/selection.lua
lua KanaSkillExp/tests/display.lua
lua KanaSkillExp/tests/integration.lua /path/to/esoui-source
luac -p KanaSkillExp/Selection.lua KanaSkillExp/KanaSkillExp.lua
```

Второй тест использует настоящий `esoui/libraries/utility/zo_hook.lua`, но
подменяет движок ESO. В игре следует проверить добавление через оба меню,
удаление, смену панели и сохранение порядка после `/reloadui`.
