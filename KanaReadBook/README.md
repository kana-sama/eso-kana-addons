# KanaReadBook

Самостоятельный аддон ESO без обязательных зависимостей.

Если игра скрывает количество книг в коллекции (например, в эйдетической памяти),
поиск по названию использует метаданные установленного LoreBooks.
Открытие по ID работает напрямую, без LoreBooks, если книга изучена.

- `/readbook Название книги` — открыть изученную книгу из библиотеки.
- Регистр не важен; название нужно указывать на языке игры. Кавычки необязательны.
- Точное совпадение имеет приоритет. Если точного нет, ищется часть названия.
- При нескольких совпадениях выводятся названия и ID; `/readbook #123` открывает конкретную книгу.
- `/readbook` — справка. Неизученные книги не открываются.

Для CShortcutPieMenu выбери выполнение команды чата и введи `/readbook Название книги` (либо ID).

После установки выполни `/reloadui`. Если новый аддон не появился, вернись к выбору персонажа и включи KanaReadBook в списке аддонов.

Автоматическая проверка: Python с установленным lupa, `python tests/test_readbook.py`.
Проверка в игре: открыть изученную книгу по полному названию, закрыть её,
повторить с частью названия; проверить список совпадений и открытие по ID.
