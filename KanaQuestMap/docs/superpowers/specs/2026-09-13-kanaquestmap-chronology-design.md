# KanaQuestMap: хронология квестов в подсказках

## Цель

Создать отдельный от обновляемого `QuestMap` аддон `KanaQuestMap`. Для
поддерживаемых The Questing Guide квестов его пины должны показывать в
подсказке номер и название сюжетной части, чтобы игрок не начинал контент
раньше времени.

## Границы

- Оригинальный `QuestMap` не изменяется.
- `KanaQuestMap` не содержит и не сохраняет собственную базу соответствий
  `questId -> дополнение`.
- Единственный источник хронологии -- установленный The Questing Guide (TQG).
- Если TQG отсутствует, отключён или не классифицирует квест, стандартная
  подсказка QuestMap остаётся без дополнительной строки.

## Интеграция

После загрузки TQG форк один раз обходит его глобальные таблицы
`ObjectiveLevelClassic`, `ObjectiveLevelDLC` и `ObjectiveLevelGroup`.
Каждый ненулевой `internalId` связывается с записью соответствующей зоны в
`ZoneLevelClassic`, `ZoneLevelDLC` или `ZoneLevelGroup`. Индекс существует
только в памяти текущей игровой сессии.

Строка подсказки берёт номер зоны из TQG и её локализованное имя через
`GetZoneNameById`. Для DLC-арок также используется название верхнего уровня
TQG. Это сохраняет решение автора TQG о порядке и автоматически принимает
его обновления без копирования данных в KanaQuestMap.

TQG не предоставляет формальный публичный API для этой информации, поэтому
KanaQuestMap использует названные таблицы как совместимый адаптер. Адаптер
проверяет типы и пропускает неполные/нестандартные записи, чтобы смена
внутренней структуры TQG не ломала карту.

## Поведение тултипа

В keyboard- и gamepad-подсказках после имени квеста добавляется строка
хронологии только при успешном поиске. Формат:

    (7.10) Северный Эльсвейр -- Глава 7: Сезон Дракона

Квесты базовой игры и группового контента используют тот же номер, который
назначает TQG; выдумывать номера или категории KanaQuestMap не будет.

## Идентичность форка

Manifest, имя папки, runtime id, SavedVariables и строки UI будут переименованы
с `QuestMap` на `KanaQuestMap`, чтобы оба аддона не загружались одновременно и
обновление QuestMap не перезаписывало форк.

## Проверка

- Lua-тест с минимальными TQG-таблицами: построение индекса, DLC-метаданные и
  безопасное пропускание `internalId = 0`.
- Lua-тест отсутствующего TQG: пустой индекс и исходная подсказка.
- Статическая проверка manifest и поиск оставшихся runtime-ссылок на `QuestMap`.
- В игре: `/reloadui`, курсор над известным квестом TQG и над квестом вне TQG.
