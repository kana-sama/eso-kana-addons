# KanaQuestMap

Надстройка над QuestMap: добавляет в подсказку квестового пина номер и
название сюжетной части из The Questing Guide, а также постоянный чёрный
список заданий.

## Установка

1. Установите и включите исходный `QuestMap`.
2. Оставьте эту папку под именем `KanaQuestMap` в `live/AddOns` и включите
   её. Она зависит от QuestMap и загружается после него.
3. При желании включите `TheQuestingGuide` и его зависимость
   `LibUespQuestData` для строки хронологии.

The Questing Guide необязателен для запуска: без него QuestMap и чёрный
список работают как обычно, но строка хронологии не показывается. KanaQuestMap не
хранит собственной базы `questId -> DLC`; он строит временный индекс из
загруженных таблиц The Questing Guide при первом открытии подсказки. Для
квестов, которых TQG не перечисляет лично, KanaQuestMap использует ESO API
`GetQuestZoneId` и показывает хронологию зоны из TQG. Поэтому side quests
в DLC-зонах получают ту же подпись, а прологи в чужих зонах по-прежнему
требуют точного сопоставления TQG.

Для сюжетных zone DLC и глав номер в подсказке — порядковый номер их релиза,
а не внутренний номер арки TQG. Например, Хьюз-Бэйн показывается как
`DLC #3: Гильдия воров -- Хьюз-Бэйн`, а Золотой Берег — как `DLC #4:
Тёмное Братство -- Золотой Берег`. Название DLC берётся из локализованной
коллекции ESO для этой зоны.

Настройки QuestMap остаются в панели QuestMap. Чёрный список находится в
отдельной панели KanaQuestMap. При первом запуске надстройка переносит старые
настройки форка в пустые поля сохранений QuestMap, не перезаписывая уже
настроенный оригинальный аддон.

Теперь QuestMap можно обновлять обычным способом: обновление не затрагивает
файлы KanaQuestMap.
