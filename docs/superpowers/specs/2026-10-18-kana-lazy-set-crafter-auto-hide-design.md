# Kana Lazy Set Crafter Auto Hide

Отдельная надстройка к установленному Dolgubon's Lazy Set Crafter 3.0.8.0.
При новом входе на поддерживаемый станок непустая общая очередь открывает
окно, пустая скрывает. Кнопка нижней штатной панели переключает окно
независимо от очереди. Заголовок кнопки: «Показать Set Crafter» или
«Скрыть Set Crafter» (английские варианты для других языков).

Начальное состояние выбирается один раз за взаимодействие со станком.
Изменение очереди, вкладки или повторный `sameStation` не отменяет ручное
переключение. Новый вход снова учитывает очередь. Существующие крестик,
команды и назначенная клавиша Set Crafter работают как прежде.

## Интеграция

Отображаемое имя: `|cFF0000Kana|r |c4488FFLazy Set Crafter|r Auto Hide`.
`Kana` красное, название исходного аддона синее, `Auto Hide` обычного цвета.

- Имя `KanaLazySetCrafterAutoHide`, зависимость `DolgubonsLazySetCrafter>=3080`, API
  `101050 101051`; без своих SavedVariables и сторонних библиотек.
- Заменить только регистрацию `EVENT_CRAFTING_STATION_INTERACT` исходного
  аддона. Сохранить включение ручного крафта через `GetAutocraft()` и
  `toggleCraftButton(true)`. Не менять файлы зависимости и её настройки.
- Поддерживаемые станки: кузница, портняжный, зачарование, столярный и
  ювелирный. Очередь общая, независимо от текущей профессии или сета.
- Переключать через `DolgubonSetCrafter.close(hidden)`: он обновляет списки
  и переключает и основное окно, и `CraftingQueueScroll`.
- Кнопка использует существующий `SET_CRAFTER_OPEN`, не забирая штатные
  действия станка. Добавлять/удалять собственную группу при показе/скрытии
  сцен крафта. Заголовок обновлять при показе/скрытии исходного окна.
- Настройки закрытия при выходе и постоянного плавающего значка сохраняются.
  Плавающий значок не появляется принудительно вместо новой нижней кнопки.
- При отсутствии необходимых объектов оставить исходный обработчик в силе.

## Сохраняемое поведение

Не менять расположение, размер, возможность перемещения и изменения размера
окна, структуру и прокрутку очереди/материалов/избранного, доступность
пунктов, навигацию, крафт и работу при меньшем разрешении/масштабе UI.
Новая кнопка использует штатную компоновку нижней панели.

## Проверка

Lua-стенд: пустая/непустая очередь, ручное переключение, изменение очереди,
повторный вход и `sameStation`, все поддерживаемые и посторонние станки,
жизненный цикл кнопки, обновление названия через исходные способы закрытия,
настройки автокрафта/выхода/значка, отсутствие зависимости.

Локальные тесты не доказывают отрисовку ESO. В клиенте после одного
`/reloadui` проверить пустую и непустую очередь, обе стороны переключения,
крестик, вкладки, выход/повторный вход, длинную очередь и меньший масштаб.
