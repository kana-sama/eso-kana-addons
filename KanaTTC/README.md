# KanaTTC

Отдельная добавка к тултипу, использующая базу цен Tamriel Trade Centre.
Выводит таблицу высотой в две строки:

| Рек. цена | Средняя | Продажи | Предложения |
| ---: | ---: | ---: | ---: |
| 950 зол. | 23.4k зол. | 42 | 126 |

- **Рек. цена** — `SuggestedPrice`, нижняя граница рекомендованной цены TTC.
- **Средняя** — `SaleAvg`, средняя цена продажи за один предмет.
- **Продажи** — `SaleEntryCount`, количество сделок.
- **Предложения** — `EntryCount`, количество предложений о продаже в данных TTC.

Обе цены обозначены значком золота. Цена меньше `10 000` выводится без
сокращения, от `10 000` до `99 999…` — с одной десятичной цифрой (`23.4k`),
от `100 000` — в целых тысячах (`126k`). Используется обычное округление:
`99 999 → 100.0k`, `125 500 → 126k`. Для малых цен сохранена точность TTC:
целые для рекомендованной цены и до двух десятичных знаков для средней.
Счётчики всегда полные, с разделителями тысяч; оба отображаются даже при
равных значениях. Отсутствующее значение — `—`, известный ноль — `0`.

Самостоятельно подключается к тултипам:
инвентарь, банк, ссылки в чате, магазины, гильдейский магазин и ремесленные
результаты. Использует публичный API базы цен TTC; его файлы и обычный вывод
не изменены. Подписи русские для русского клиента, английские для остальных.

Разместите папку в `AddOns/eso-kana-addons/KanaTTC`, включите `KanaTTC`
и `Tamriel Trade Centre` в списке аддонов и выполните `/reloadui`.
Таблица KanaTTC не зависит от настроек TTC: появляется и при `/ttc off`,
и при отключении всех отдельных строк TTC. Обычный блок TTC управляется
его собственными настройками. Чтобы оставить только компактную таблицу,
отключите обычный вывод цен в TTC; таблица KanaTTC останется.

Проверки из корня `eso-kana-addons`:

```sh
lua KanaTTC/tests/test_tooltips.lua
luac -p KanaTTC/KanaTTC.lua
```

Автоматические проверки подтверждают выбор полей, форматирование и жизненный
цикл таблицы. Внешний вид проверяется отдельно в ESO после `/reloadui`.
