# KanaCooldownPanel

Отдельный аддон с компактными таймерами пяти навыков штатной панели ESO.
Работает без KanaAuras; для настроек используется общая библиотека
**LibAddonMenu-2.0**. Время берётся из
`GetActionSlotEffectTimeRemaining`: отдельных конфигов навыков и эффектов нет.

## Панели

- По умолчанию две строки: сверху неактивная панель оружия, снизу текущая.
- При включении фиксированных панелей фронтбар (панель основного оружия)
  остаётся сверху или снизу независимо от смены оружия.
- В форме вервольфа или с кольцом Дубовой души в любом слоте — одна текущая строка.
- Временная специальная панель тоже отображается одной строкой.
- Позиции квадратов соответствуют слотам навыков слева направо. Ультимейт не входит.

| Состояние | Отображение |
| --- | --- |
| Навык скрыт, слот пуст или нет неважного аптайма | Пустое место без квадрата |
| Эффект активен | Полупрозрачный чёрный квадрат или иконка навыка, белый таймер |
| До окончания важного эффекта меньше 2 секунд | Оранжевый фон, белый таймер |
| Важного эффекта нет в бою | Красный пульсирующий фон с `!` или золотистая пульсирующая рамка |

Вне боя отсутствующий эффект всегда оставляет пустое место. Активные таймеры
остаются видимыми. При открытии игровых меню панель скрывается вместе с HUD.
По умолчанию все установленные навыки считаются важными: для навыков без
отслеживаемого игрой эффекта можно отключить напоминание через меню.

## Настройки отображения

**Настройки → Дополнения → KanaCooldownPanel**:

1. **Фиксированные панели** — закрепляет основную и запасную панели за строками.
2. **Положение фронтбара: сверху / снизу** — доступно только при включённой фиксации.
3. **Тип alert-иконки** — `!` на красном фоне или светящаяся золотистая рамка.
4. **Тип иконки** — квадратик или иконка навыка из штатного слота ESO.

Для иконки навыка непрозрачность равна `0.9 × (1 − остаток / длительность)`:
0 при полном таймере, 0,45 на половине, почти 0,9 перед окончанием и сразу
1 при отсутствии эффекта. Длительность берётся из `GetActionSlotEffectDuration`.
Белый таймер сохраняет полную непрозрачность. Красное предупреждение рисуется
поверх иконки, золотая рамка — вокруг неё; золотой вариант не показывает `!`.
Для активного важного эффекта с остатком меньше двух секунд сохраняется оранжевое
предупреждение. Пустые места и скрытие отсутствующего эффекта вне боя работают
при любом стиле.

Настройки отображения общие для персонажей, применяются сразу и сохраняются
в `KanaCooldownPanelSettings`. По умолчанию сохранён прежний вид: динамические
панели, квадрат и красное предупреждение. Для интерфейса настроек используется
установленная общая LibAddonMenu-2.0, копия библиотеки в аддон не встроена.

## Настройки навыков

Нажми правой кнопкой на навык **штатной панели ESO** и переключи:

- **Не показывать в панели кулдаунов** — оставляет пустое место в этой позиции.
- **Аптайм не важен** — показывает только квадрат или иконку с активным таймером;
  оранжевого и красного напоминания не будет.

Настройки сохраняются отдельно для каждого персонажа и следуют за навыком при
перестановке между слотами и панелями. Ранги и морфы одного навыка используют
общую настройку; созданные через чаропись навыки определяются по ID гримуара.
Для навыков без данных о прогрессии используется ID способности.

## Положение и установка

Включи курсор и перетащи видимый квадрат вверх или вниз левой кнопкой мыши.
По горизонтали панель закреплена по центру. Высота хранится в
`KanaCooldownPanelSettings.y`, настройки навыков — в `characters[characterId].skills`.
Если при первом запуске включён KanaAuras, старое значение
`KanaAurasSettings.mirrorY` переносится автоматически. После этого KanaAuras
для работы панели не нужен.

После добавления папки аддона перезапусти ESO и включи **KanaCooldownPanel**
в списке дополнений. Для последующих изменений Lua достаточно `/reloadui`.

## Проверка

`python3 tests/run.py` запускает проверки через `lupa.lua51` (Lua 5.1).
Проверяются состояния и порог 2000 мс, фиксированный и динамический порядок,
оба слота кольца, вервольф, стили предупреждений, прозрачность иконок, зависимые
настройки, меню и сохранение, перенос высоты, перетаскивание и сцены.

В игре нужно проверить настройки отображения, внешний вид и пульсацию, правый клик на обычном навыке
и навыке вервольфа, возврат из меню вне боя и сохранение после `/reloadui`.
Автотесты используют макеты API и не заменяют проверку внутри ESO.
