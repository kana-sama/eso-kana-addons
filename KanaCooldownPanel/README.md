# KanaCooldownPanel

Отдельный аддон с компактными таймерами пяти навыков штатной панели ESO.
Работает без KanaAuras и дополнительных библиотек. Время берётся из
`GetActionSlotEffectTimeRemaining`: отдельных конфигов навыков и эффектов нет.

## Панели

- Обычно две строки: сверху запасная панель оружия, снизу текущая.
- В форме вервольфа или с кольцом Дубовой души в любом слоте — одна текущая строка.
- Временная специальная панель тоже отображается одной строкой.
- Позиции квадратов соответствуют слотам навыков слева направо. Ультимейт не входит.

| Состояние | Отображение |
| --- | --- |
| Навык скрыт, слот пуст или нет неважного аптайма | Пустое место без квадрата |
| Эффект активен | Полупрозрачный чёрный фон, белый таймер |
| До окончания важного эффекта меньше 2 секунд | Оранжевый фон, белый таймер |
| Важного эффекта нет в бою | Красный пульсирующий фон, белый `!` |

Вне боя отсутствующий эффект всегда оставляет пустое место. Активные таймеры
остаются видимыми. При открытии игровых меню панель скрывается вместе с HUD.
По умолчанию все установленные навыки считаются важными: для навыков без
отслеживаемого игрой эффекта можно отключить напоминание через меню.

## Настройки навыков

Нажми правой кнопкой на навык **штатной панели ESO** и переключи:

- **Не показывать в панели кулдаунов** — оставляет пустое место в этой позиции.
- **Аптайм не важен** — показывает только чёрный квадрат с активным таймером;
  оранжевого и красного напоминания не будет.

Настройки сохраняются отдельно для каждого персонажа и следуют за навыком при
перестановке между слотами и панелями. Ранги и морфы одного навыка используют
общую настройку; созданные через чаропись навыки определяются по ID гримуара.
Для навыков без данных о прогрессии используется ID способности.

## Положение и установка

Включи курсор и перетащи видимый квадрат вверх или вниз левой кнопкой мыши.
По горизонтали панель закреплена по центру. Высота хранится в
`KanaCooldownPanelSettings.y`, настройки навыков — в `characters[characterId].skills`.
Если при первом запуске включён KanaAuras, старое значение
`KanaAurasSettings.mirrorY` переносится автоматически. После этого KanaAuras
для работы панели не нужен.

После добавления папки аддона перезапусти ESO и включи **KanaCooldownPanel**
в списке дополнений. Для последующих изменений Lua достаточно `/reloadui`.

## Проверка

`python3 tests/run.py` запускает проверки через `lupa.lua51` (Lua 5.1).
Проверяются состояния и порог 2000 мс, смена панелей, оба слота кольца,
вервольф, меню и сохранение настроек, перенос высоты, перетаскивание и сцены.

В игре нужно проверить внешний вид и пульсацию, правый клик на обычном навыке
и навыке вервольфа, возврат из меню вне боя и сохранение после `/reloadui`.
Автотесты используют макеты API и не заменяют проверку внутри ESO.
