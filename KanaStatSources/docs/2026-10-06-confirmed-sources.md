# Подтверждённые источники из дампа 1.0.4

Цель: сократить «Неизвестно» только за счёт проверенных источников. Использовать последний согласованный дамп #3, API 101051, уровень 50, CP527, без battle leveling. Интерфейс тултипа не менять.

## Доказательства

- [Формулы автора UESP, Update 32](https://github.com/uesp/uesp-esochardata/blob/bbe4939b259acfcf9b7dd05e14f7da4ba7c4a8d9/editBuild.class.php#L2437): `round(5.592 * Level + 29.4)` для здоровья, `round(9.30612 * Level + 48.7)` для магии и запаса сил. При уровне 50 получаются 309 и 514. Применение этих баз вместе с текущими описаниями пассивок воспроизводит три итоговых значения нового дампа. Правила ограничить уже поддержанным контекстом API 101051, уровень 50 CP160+, без battle leveling; другие уровни по старой формуле не экстраполировать.
- [Там же, здоровье](https://github.com/uesp/uesp-esochardata/blob/bbe4939b259acfcf9b7dd05e14f7da4ba7c4a8d9/editBuild.class.php#L2358): вложенные атрибуты входят в сумму перед процентным модификатором. Native значение атрибута в новом дампе — 122 здоровья или 111 магии/сил за очко, без 5% «Джаггернаута». Недостающие 390 HP — процент от 7808 вложенных в здоровье очков, с учётом общего округления.
- [ZOS Update 26](https://forums.elderscrollsonline.com/en/discussion/528633/pc-mac-patch-notes-v6-0-5-greymoor-update-26/p1): базовое сопротивление криту появляется с уровня 10. [UESP Update 29](https://github.com/uesp/uesp-esochardata/blob/0e58d0871bd63b994d56c6572d400e500b2e326a/editBuild.class.php#L2691) задаёт базовый рейтинг 1320; Update 32 сохраняет его, новый дамп подтверждает значение. Числовое правило ограничить проверенным контекстом уровня 50.
- [Исходные собранные UESP данные навыка](https://chat.uesp.net/esochardata/viewBuildData.php?id=82020&raw=) содержат условие Sword and Board: одноручное оружие и щит. В новом дампе ID 29397, изученный ранг I, активная линия, описание даёт 3% силы оружия и заклинаний. На передней панели топор и щит; задняя панель с посохом не удовлетворяет условию. Процент читать из текущего описания, проверять типы обеих рук активной панели. Не выводить величину из остатка и не предполагать ранги/ID, которых нет в данных.
- «Эрудиция», ID 185239, содержит вводную фразу перед безусловным бонусом. Её полный native RU-текст в новом дампе задаёт 18% восстановления магии и запаса сил. Правило сопоставляет полный проверенный RU/EN текст, включая вводную фразу, и читает процент из него. Не пропускать произвольную вводную фразу в общем парсере; описание с новым условным хвостом не принимать.

## Ограничения

- Базовый рейтинг крита без бонусов из API — 2181, тогда как калибровка `GetCriticalStrikeChance` переводит базовые 10% в 2191.2. Точное объяснение расхождения не доказано; прежний подписанный остаток -10 рейтинга (около -0.05%) оставить. Не трактовать `DONT_APPLY_BONUS` как универсальную чистую базу.
- Не добавлять неактивные proc-сеты, временные бонусы изученных пассивок, способности с панели оборотня на обычной панели, множители вампиризма и неизвестную вторую руку.
- Проверить суммы всех 15 характеристик, сырые суммы и происхождение новых вкладов. Мутация native итога не допускается. Синтетически добавленный неизвестный бонус должен остаться «Неизвестно».
- Сохранить native effectiveFlat Мундуса; поменять только атрибуты, включив их в обычную flat-базу процентных групп.
- Проверки в Lua 5.1 и Lua 5.4 подтверждают вычисления; работа нового кода в клиенте требует `/reloadui`.
