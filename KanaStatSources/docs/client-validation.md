# Проверка в клиенте ESO

Статус: **не выполнена**. Lua-тесты проверяют расчёт и контракты контролов; внешний вид и фактическую запись SavedVariables подтверждает только клиент.

1. Включить KanaStatSources и выполнить `/reloadui`. До открытия окна персонажа вызвать `/kanastats dump`; после следующего `/reloadui` проверить новый ID в `live/SavedVariables/KanaStatSources.lua`.
2. Навести на каждую из 15 основных характеристик. Проверить native заголовок/описание и иконку Мундуса; две колонки без заголовков, короткие жёлтые названия и белые эффекты, жирный шрифт; маленькие иконки предметов/еды/пассивок и зелёную/синюю/красную ветку CP. Сумма вкладов с signed остатком должна сходиться; для крита строки показывают проценты, внизу видны рейтинг и формула.
3. Проверить длинные русские названия, большой UI scale и низкое разрешение. Ширина достаточна для названий в одну строку, ограничена экраном; описание и таблица занимают одну ширину без масштабирования. Итог видим, колесо на строке стата достигает последнего источника.
4. Повторно наводить на один стат и оставлять мышь неподвижной на несколько секунд. Проверить, что конец многострочного описания не исчезает после фонового обновления. Сменить панель, предмет, еду и CP при открытом тултипе. Проверить обновление без скачков размера и сброса прокрутки. При смене подкласса пассивки отключённой линии не должны давать вклад.
5. Добавить атрибут в черновик: текущий итог не меняется, появляется отдельный предпросмотр. Подтвердить или отменить распределение и проверить результат.
6. Отвести мышь, закрыть окно персонажа, открыть другой InformationTooltip. Строки KanaStatSources не остаются в чужом тултипе, его исходная ширина и ограничения восстанавливаются.
7. Сделать дампы до и после каждого изменения и сопоставить rawUnknown с исходными описаниями. Проверить отрицательный остаток, если появится. После 11 дампов должно остаться десять записей с неповторяющимися ID.
