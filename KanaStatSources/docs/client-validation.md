# Проверка в клиенте ESO

Статус: **не выполнена**. Lua-тесты проверяют расчёт и контракты контролов; внешний вид и фактическую запись SavedVariables подтверждает только клиент.

1. Включить KanaStatSources и выполнить `/reloadui`. До открытия окна персонажа вызвать `/kanastats dump`; после следующего `/reloadui` проверить новый ID в `live/SavedVariables/KanaStatSources.lua`.
2. Навести на каждую из 15 основных характеристик. Проверить native заголовок/описание и иконку Мундуса; две колонки без заголовков, короткие жёлтые названия и белые эффекты, жирный шрифт; маленькие иконки предметов/еды/пассивок, базового значения, атрибутов и зелёную/синюю/красную ветку CP. Сумма вкладов с signed остатком должна сходиться; для крита есть базовые 10%, строки показывают проценты, внизу только «Итого» и процент. Нулевые бонусы (например, «Решимость» без тяжёлой брони) отсутствуют. При базе силы 3148 и бонусах 14% + 20% итог 4218 не должен содержать «Неизвестно −1».
3. Проверить длинные русские названия, большой UI scale и низкое разрешение. Ширина равна месту для названия, иконки, отступа и значения, минимум штатные 350 UI units; описание переносится внутри неё. При появлении русского предпросмотра атрибутов ширина не увеличивается. Итог видим, колесо на строке стата достигает последнего источника.
4. Повторно наводить на один стат и оставлять мышь неподвижной на несколько секунд. Проверить, что конец многострочного описания не исчезает после фонового обновления. Сменить панель, предмет, еду и CP при открытом тултипе. При неизменных источниках размер сохраняется; если названия становятся длиннее/короче, новая ширина сразу вмещает строки, заголовок и итог остаются внутри окна. Прокрутка сохраняется в допустимых пределах. При смене подкласса пассивки отключённой линии не должны давать вклад.
5. Добавить атрибут в черновик: текущий итог не меняется, появляется отдельный предпросмотр. Подтвердить или отменить распределение и проверить результат.
6. Отвести мышь: исчезает весь заполненный тултип без маленького пустого квадрата. Вернуть мышь до конца исчезновения: новое содержимое видно полностью. Закрыть окно персонажа, затем открыть карту и тултипы нескольких отметок. Размер их фона соответствует тексту; отдельный тултип статов не меняет InformationTooltip и не оставляет в нём своих строк/ограничений.
7. Сделать дампы до и после каждого изменения и сопоставить rawUnknown с исходными описаниями. Проверить отрицательный остаток, если появится. После 11 дампов должно остаться десять записей с неповторяющимися ID.
