# Проверка в клиенте ESO

Статус: **не выполнена**. Lua-тесты проверяют расчёт и контракты контролов; внешний вид и фактическую запись SavedVariables подтверждает только клиент.

1. Включить KanaStatSources и выполнить `/reloadui`. До открытия окна персонажа вызвать `/kanastats dump`; после следующего `/reloadui` проверить новый ID в `live/SavedVariables/KanaStatSources.lua`.
2. Навести на каждую из 15 основных характеристик. Проверить сохранение native заголовка/описания и иконки Мундуса; сумму строк с signed остатком; рейтинг и формулу обоих критических шансов.
3. Проверить длинные русские названия, большой UI scale и низкое разрешение. Итог должен оставаться видимым, колесо на строке стата должно достигать последнего источника.
4. Сменить панель, предмет, еду и CP при открытом тултипе. Проверить обновление. При смене подкласса пассивки отключённой линии не должны давать вклад.
5. Добавить атрибут в черновик: текущий итог не меняется, появляется отдельный предпросмотр. Подтвердить или отменить распределение и проверить результат.
6. Отвести мышь, закрыть окно персонажа, открыть другой InformationTooltip. Строки KanaStatSources не должны остаться в чужом тултипе.
7. Сделать дампы до и после каждого изменения и сопоставить rawUnknown с исходными описаниями. Проверить отрицательный остаток, если появится. После 11 дампов должно остаться десять записей с неповторяющимися ID.
