# KanaStatSources

Таблица источников в штатных тултипах 15 основных характеристик персонажа: максимальные ресурсы, восстановление, сила оружия/заклинаний, критический шанс, пробивание и сопротивления. Интерфейс клавиатуры и мыши, ESO API 101051, без зависимостей.

Включите **KanaStatSources** в списке аддонов и выполните `/reloadui`. Наведите курсор на характеристику в окне персонажа. Таблица показывает источник, исходный бонус и вклад в итог. Колесо мыши на строке характеристики прокручивает источники. Итог закреплён внизу; для критического шанса дополнительно показаны суммарный рейтинг и формула перевода в процент.

Сумма видимых числовых строк всегда равна текущему значению API. Подписанный остаток **«Неизвестно»** может быть отрицательным и включает нераспознанные источники, масштабирование и округление. Черновые атрибуты показываются отдельным предпросмотром. При нестабильном снимке объяснённые источники исключаются, чтобы не смешивать разные состояния персонажа.

Распознаются: база ресурсов/силы для уровня 50 CP160+ без battle leveling; потраченные атрибуты; броня, сила основной руки, постоянные зачарования и поддержанные свойства; постоянные пороги сетов; безусловные изученные пассивки активных линий; текущие бонусы действующих CP; еда/напитки; native-вклады Мундуса; простые действующие бафы и дебафы. Числа в RU/EN описаниях берутся из текущего клиента.

Условные бонусы за число предметов/навыков, оружейные специализации, масштабирование второй руки, некоторые CP-форматы, особые сетовые proc, проклятия и окружение могут остаться неизвестными. Неизвестные проценты не умножают итог автоматически. На другом языке остаются подписи EN, native-вклады и остаток; текстовые правила RU/EN не применяются. Окно дополнительных характеристик и gamepad-тултипы не расширяются.

## Диагностический снимок

Введите **`/kanastats dump`**. Команда работает и до открытия окна персонажа. Она сохраняет последние десять снимков с последовательными ID в `KanaStatSourcesSaved.dumps`. После `/reloadui` или выхода из игры данные появятся в:

`Documents/Elder Scrolls Online/live/SavedVariables/KanaStatSources.lua`

В снимок входят все основные и дополнительные значения API, обе панели, изученные пассивки активных и неактивных линий, сохранённые CP и слоты, надетые предметы и их native metadata, сетовые пороги, все текущие эффекты и их полные описания, Мундус, контекст уровня/проклятия/battle leveling, критические пробы, вклад каждого источника, видимый и сырой остатки, кандидаты, ошибки API и статусы доступности категорий. Файл предназначен для анализа на компьютере; аддон не отправляет данные по сети.

Для поиска недостающего источника сравните два дампа до и после одного изменения: например, снятия предмета, окончания еды, смены CP или панели. Смотрите `snapshot`, `contributions`, `breakdowns[stat].rawUnknown`, `diagnostics` и `snapshot.errors`. Кандидат не считается подтверждённым числовым вкладом.

Правила и ограничения описаны в [docs/research.md](docs/research.md). Автоматические проверки: `lua KanaStatSources/tests/run.lua` из корня репозитория. Проверка в игре: [docs/client-validation.md](docs/client-validation.md).
