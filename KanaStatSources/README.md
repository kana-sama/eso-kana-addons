# KanaStatSources

Таблица источников в штатных тултипах 15 основных характеристик персонажа: максимальные ресурсы, восстановление, сила оружия/заклинаний, критический шанс, пробивание и сопротивления. Интерфейс клавиатуры и мыши, ESO API 101051, без зависимостей.

Включите **KanaStatSources** в списке аддонов и выполните `/reloadui`. Наведите курсор на характеристику в окне персонажа. Две колонки показывают короткое название с маленькой иконкой и числовой эффект. Названия жёлтые, значения белые, весь текст жирным штатным шрифтом характеристик; заголовков колонок нет. Иконки CP соответствуют цветным веткам. Базовое значение и атрибуты тоже имеют иконки; иконки атрибутов такие же, как в инфо-панели KanaWardrobe. Для критического шанса все значения показаны в процентах, внизу — только **«Итого»** и текущий процент.

Ширина равна месту для самой длинной строки: иконка, название, отступ и значение; минимум — штатные 350 единиц интерфейса, максимум — граница экрана. Названия занимают одну строку. Описание переносится внутри этой же ширины. При неизменных строках обновления сохраняют размер; появление более длинного источника сразу пересчитывает ширину. Если строки не помещаются, оставьте курсор на характеристике и вращайте колесо мыши; итог закреплён внизу.

Сумма числовых вкладов равна текущему значению API; проценты крита в строках округляются для отображения. Округление распределяется между дробными вкладами после округления общей суммы, поэтому отдельные процентные строки не создают лишнюю единицу. Подписанный остаток **«Неизвестно»** сохраняет реальные расхождения и может быть отрицательным. Нулевые строки скрыты, исходные данные остаются в дампе. Черновые атрибуты показываются отдельным предпросмотром. При нестабильном снимке объяснённые источники исключаются, чтобы не смешивать разные состояния персонажа.

Тултип статов использует отдельный штатный контрол ESO. Содержимое сохраняется до завершения анимации исчезновения. Общий тултип карты и других окон не изменяется.

Для процентных модификаторов показаны числовой вклад и процент в скобках. Слот предмета, ранг навыка, сохранённые очки CP и база умножения остаются в диагностическом дампе. Одинаковые предметы в разных слотах имеют отдельные строки с собственными вкладами.

Расчёт общий для всех характеристик и обновляется при изменениях персонажа. Снаряжение и неизменные описания кешируются; повторное наведение не собирает весь build заново. Обновления не сбрасывают позицию прокрутки.

Распознаются: базовый критический шанс 10%; база ресурсов/силы, восстановления 309/514/514 и сопротивления криту 1320 для уровня 50 CP160+ без battle leveling; потраченные атрибуты с процентными модификаторами; броня, сила основной руки, постоянные зачарования и поддержанные свойства; постоянные пороги сетов; безусловные изученные пассивки активных линий, включая «Эрудицию»; «Щит и меч» при одноручном оружии и щите на активной обычной панели; текущие бонусы действующих CP; еда/напитки; native-вклады Мундуса; простые действующие бафы и дебафы. Числа в RU/EN описаниях берутся из текущего клиента.

Условные бонусы за число предметов/навыков, оружейные специализации, масштабирование второй руки, некоторые CP-форматы, особые сетовые proc, проклятия и окружение могут остаться неизвестными. Неизвестные проценты не умножают итог автоматически. На другом языке остаются подписи EN, native-вклады и остаток; текстовые правила RU/EN не применяются. Окно дополнительных характеристик и gamepad-тултипы не расширяются.

## Диагностический снимок

Введите **`/kanastats dump`**. Команда работает и до открытия окна персонажа. Она сохраняет последние десять снимков с последовательными ID в `KanaStatSourcesSaved.dumps`. После `/reloadui` или выхода из игры данные появятся в:

`Documents/Elder Scrolls Online/live/SavedVariables/KanaStatSources.lua`

В снимок входят все основные и дополнительные значения API, обе панели, изученные пассивки активных и неактивных линий, сохранённые CP и слоты, надетые предметы и их native metadata, сетовые пороги, все текущие эффекты и их полные описания, Мундус, контекст уровня/проклятия/battle leveling, критические пробы, вклад каждого источника, видимый и сырой остатки, кандидаты, ошибки API и статусы доступности категорий. Файл предназначен для анализа на компьютере; аддон не отправляет данные по сети.

Для поиска недостающего источника сравните два дампа до и после одного изменения: например, снятия предмета, окончания еды, смены CP или панели. Смотрите `snapshot`, `contributions`, `breakdowns[stat].rawUnknown`, `diagnostics` и `snapshot.errors`. Кандидат не считается подтверждённым числовым вкладом.

Правила и ограничения описаны в [docs/research.md](docs/research.md). Автоматические проверки: `lua KanaStatSources/tests/run.lua` из корня репозитория. Проверка в игре: [docs/client-validation.md](docs/client-validation.md).
