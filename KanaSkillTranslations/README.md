# Kana Skill Translations

Переводы в дополнительных тултипах Harven's Improved Skills Window.
Требуются Name Language Ninja, Harven's Improved Skills Window и LibMultilingualName
с включёнными языковыми модулями для нужных языков.

Аддон использует настройки Name Language Ninja: языки названий и описаний,
цвета названий, показ описаний, скрытие языка клиента и разделителя,
включение вывода в тело тултипа. Собственных настроек и SavedVariables нет.
Настройки читаются при каждом заполнении тултипа.

Поддержаны оба окна сравнения, морфы, конкретные ранги и следующий ранг пассивки.
Если перевода нет в библиотеке, соответствующая строка пропускается.
Описания выводятся как в Ninja, включая имеющиеся в базе шаблоны `<<1>>`.
Выбор языков описаний действует независимо от выбора языков названий.

После установки: включить Kana Skill Translations в списке аддонов.
Если новый аддон ещё не появился, перезапустить клиент игры.

Проверка в игре: открыть навыки и включить подробности Harven; проверить
оба морфа, следующий/максимальный ранг пассивки, повторное наведение,
а затем выключить описания или сменить языки в настройках Ninja.

Проверка без ESO (заглушки игрового API, не проверяет расположение на экране):

```sh
lua tests/test_tooltips.lua .
```
