# KanaQuestZoneFix

Исправляет 19 ошибочных ответов `GetQuestZoneId()` из
[сообщения Antis3n1l на форуме ESO](https://forums.elderscrollsonline.com/en/discussion/698890/getquestzoneid-returns-wrong-zoneid-for-some-quests).

## Использование

Включите **KanaQuestZoneFix** в списке дополнений и выполните `/reloadui`.
Если новый аддон ещё не появился в списке, перезапустите игру.
После обновлений LibQuestData или LibUespQuestData повторно накатывать патч
не нужно: он находится в отдельной папке и применяется при загрузке интерфейса.
Настроек нет. LibQuestData — необязательная зависимость. Для удаления исправлений отключите аддон и
выполните `/reloadui`.

## Область исправления

LibQuestData не хранит zoneId в таблице quest_data. Установленная
LibUespQuestData получает зону через игровую функцию GetQuestZoneId;
напрямую её используют также KanaZoneGoals и KanaQuestMap.
Поэтому аддон оборачивает эту функцию глобально. Он исправляет её ответы
для всех вызывающих её потребителей, а не изменяет файлы библиотек.

Замена происходит только при совпадении ID задания и известной ошибочной зоны.
Уже исправленные игрой значения и любые другие ответы сохраняются.
Также удаляется ошибочная точка задания 7237 (Upstart Emperor) на карте
Морнхолда из LibQuestData 2.79. Это задание Lep Seclusa, а указанная точка
и её координаты относятся к другой карте. Новая точка не создаётся:
проверенных координат в Lep Seclusa нет. Другие точки сохраняются, включая
точки этого задания на других картах в будущих обновлениях библиотеки.
Исправление выполняется в памяти после загрузки данных LibQuestData.
Аддоны, сохранившие старую функцию или вычислившие зону во время загрузки
файлов до этого патча, могут потребовать явной зависимости от KanaQuestZoneFix.

## Проверка

Из папки AddOns: `lua KanaQuestZoneFix/tests/test_zone_fix.lua`.
Проверка данных LibQuestData: `lua KanaQuestZoneFix/tests/test_libquestdata_patch.lua`.
Проверяются все 19 замен, пропуск остальных значений, сохранение будущих
исправлений и оба метода определения зоны установленной LibUespQuestData.
Игровое API в тесте подставлено; итоговую работу интерфейса нужно проверить в ESO.

В игре после загрузки аддона:
`/script d(GetQuestZoneId(4303))` — должно вывести `934`.

## Взаимоисключающие задания

Расширяет `LibQuestData_Internal:show_breadcrumb_quest` проверкой взаимных
связей в `LibQuestData.conditional_quest_list`. Например, после настоящего
завершения «Во имя высшего блага» (3598) «Заблудший брат» (3595)
считается недоступным, и наоборот. Используется база установленной библиотеки,
без отдельного списка пар. Односторонние связи не считаются взаимоисключением.
Проверяется `HasCompletedQuest`, а не `LibQuestData.completed_quests`, куда
библиотека добавляет также условные завершения альтернатив. Активные и уже
выполненные задания сохраняют прежний результат фильтра.
KanaZoneGoals использует этот фильтр для красных строк и исключения из счётчика.
Файлы KanaZoneGoals и LibQuestData не изменяются.

Тест: `lua KanaQuestZoneFix/tests/test_availability.lua` из папки eso-kana-addons.
