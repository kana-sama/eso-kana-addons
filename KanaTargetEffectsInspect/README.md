# Kana Target Effects Inspect

Сохраняет бафы и дебафы последней цели на экране при включении курсора, чтобы можно было навести мышь на иконки и прочитать их названия.

Иконки остаются на прежних местах до выхода из режима курсора. Это снимок эффектов в момент перехода: таймеры доходят до нуля, но иконки не исчезают во время чтения. После выключения курсора возвращается обычное отображение текущей цели.
