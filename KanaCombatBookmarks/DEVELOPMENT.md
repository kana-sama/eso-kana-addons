# KanaCombatBookmarks

Закладки для подробного лога Combat Metrics. После непонятного события нажми бинд: появится угловое уведомление с запоминающимся именем («Армагеддон», «Кракен», «Супернова») и прозвучит короткий щелчок.

1. Включи **KanaCombatBookmarks** вместе с Combat Metrics, CombatMetricsFightData и LibCombat.
2. В **Настройки → Управление → KanaCombatBookmarks** назначь «Поставить закладку в Combat Metrics».
3. Нажимай в бою или в течение 10 секунд после его окончания, пока не начался следующий бой.
4. Открой подробный лог CMX и выбери имя в списке справа. Золотая полоса с белым именем по центру окажется в середине окна; выше — события до нажатия, ниже — после.

Переключатели событий и выбранные цели/способности продолжают фильтровать события, но не закладки. Список закладок прокручивается. Его ширина подстраивается под самое длинное имя или заголовок; место для ползунка добавляется только при переполнении по высоте. Закладки выглядят как строки бафов CMX без иконок: имя слева, без таймштампа и рамки, с подсветкой при наведении и выборе. Золотое заполнение показывает время в процентах от длины боя; отметка после конца боя заполняет строку полностью. В самом логе закладка занимает отдельную золотую полосу с белым именем по центру; высота соседних событий учитывает переносы. В копируемом тексте точное время сохраняется. Страницы, колесо, ползунок и копирование видимого текста остаются доступны; переход подгружает контекст через границы страниц. У краёв боя добавляется пустое место для центрирования.

Закладки сохраняются штатной кнопкой сохранения боя CMX; исходный лог и статистика не изменяются. Сохраняй бой **после** последней закладки: ранее сохранённый бой остаётся снимком на момент сохранения. Если в сохранённом бое нет подробного лога, имена и время остаются, но переход к событиям недоступен. Логи CMX с несогласованными ID участников восстанавливаются при загрузке, без перезаписи сохранения. В облегчённом режиме или без записываемого боя бинд сообщает об отказе без щелчка.

48 имён перемешиваются без повторов внутри боя. Следующие циклы добавляют `· 2`, `· 3`. Сохранённые имена не меняются. Пул — отбор и перевод [Corpora monsters](https://github.com/dariusk/corpora/blob/master/data/mythology/monsters.json), [greek_monsters](https://github.com/dariusk/corpora/blob/master/data/mythology/greek_monsters.json) под [CC0](https://github.com/dariusk/corpora#license), дополненный названиями явлений. Сеть для работы не нужна.

Совместимость проверяется по структуре UI Combat Metrics 1.7.8 / CombatMetricsFightData 22 / LibCombat 89. При отсутствии ожидаемых контролов встроенный просмотр CMX сохраняется. Звук — щелчок фиксации штифта замка `SOUNDS.LOCKPICKING_CHAMBER_LOCKED`; положение уведомления задаёт ESO.

## Проверка

Из корня репозитория: `for test in KanaCombatBookmarks/tests/test_*.lua; do lua "$test" || exit; done`. Тесты сохранения и фильтров используют настоящий установленный код CMX/LibDataEncode из родительского каталога; для другого расположения задай `ESO_ADDONS_ROOT`.

В клиенте ещё необходимо подтвердить отрисовку, центрирование с переносами и разным масштабом, бинд и характер щелчка. События выводятся отдельными Label с измеренной высотой; TextBuffer содержит невидимые непустые служебные сообщения для штатного управления прокруткой CMX. Число видимых строк рассчитывается по высоте окна и шрифта, без запроса к очищенному буферу. Регрессии проверяют отбрасывание пробелов, нулевые показатели пустого буфера, свежий и сохранённый бой, узкий экран и возврат к штатному просмотру без закладок. Один сценарий: несколько меток в длинном бою (включая два быстрых нажатия и метку после смерти/конца), переходы с фильтрами и маленьким окном, сохранение полного боя → один `/reloadui` → загрузка и повторные переходы. Локальные тесты эту проверку не заменяют.
