# KanaCooldownMetronome

Надстройка для Combat Metronome: круговой кулдаун с прозрачным центром,
пинг-зоной, обычными цветами и исходным расчётом времени.

## Использование

Включите Combat Metronome и KanaCooldownMetronome в списке аддонов.
Откройте настройки **Combat Metronome - Progressbar → Радиальный кулдаун**.
Там находятся переключатель, координаты центра, Center Horiz / Center Vert,
внешний и внутренний радиусы. Отключение переключателя возвращает обычную полосу.

Файлы Combat Metronome не изменяются. Его можно обновлять обычным способом,
оставляя папку KanaCooldownMetronome установленной. Надстройка подключается
к Lua-интерфейсу версии 1.7.6 (API 101050); изменения этого интерфейса в будущих
версиях могут потребовать обновления надстройки.

## Сохранения

Собственные настройки находятся в KanaCooldownMetronomeSavedVars
(файл SavedVariables/KanaCooldownMetronome.lua, имя файла определяется ESO).
Профили следуют выбору Combat Metronome: общие для аккаунта или отдельные для
персонажа. Параметры старого патча импортируются автоматически из всех его
профилей; существующие настройки надстройки не перезаписываются.
Цвета, пинг, видимость и отсчёт остаются под управлением Combat Metronome.

## Реализация и проверки

Bootstrap.lua задаёт пространство имён и значения по умолчанию.
Radial.lua содержит перенесённый рендер на CT_BACKDROP и элементы настроек.
Integration.lua подключает его после загрузки базового аддона, дополняет
существующую таблицу настроек LAM и оборачивает только нужные функции/экземпляр
полосы. Общая библиотека DariansUtilities не изменяется.

Тесты tests/*.lua запускаются в отдельных Lua 5.1 окружениях:
arg[1] — путь к KanaCooldownMetronome, arg[2] — путь к CombatMetronome.
Проверяются полный охват круга, цвета, пинг, повторное использование контролов,
подключение после инициализации, перенос профилей и возврат линейного режима.
Отрисовка в клиенте ESO требует отдельной проверки после /reloadui.
