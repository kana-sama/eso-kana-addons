# KanaZoneGoals

Дополнительные цели внутри штатного блока **«Исследование области» на экране карты** (интерфейс клавиатуры и мыши).
Откройте карту и прокрутите список исследования области вниз до «Дополнительные цели».

## Управление

- Категория выглядит как штатная строка карты: иконка и прогрессбар со счётчиком.
- Наведение показывает прокручиваемый список целей и подцелей с галочками выполнения.
- Нажатие на достижение в подсказке открывает его в журнале; на сет — коллекцию сетов области.
- В подсказке показаны критерии достижений; для сетов — только названия сетов.
- Рыбы сгруппированы по водоёму, названия окрашены по редкости Rare Fish Tracker.
- Сеты данжей исключены по умолчанию; переключатель «Исключать сеты данжей» находится в `/kzg`.
- В категории «Древности» учитывается только первая раскопка каждой части. Кодекс и повторные раскопки не учитываются.
- Включены мифики, маунты, эмоции, украшения, раскраски, мотивы и другие предметные/коллекционные награды. Исключены ценные предметы для продажи, осадное оружие и мебель (включая коллекционную).
- У неполученной древности указаны конечная награда и источник зацепки из Lead List; название древности, награда и источник показаны отдельными строками. Награда использует собственный цвет редкости, источник — обычный серый шрифт. Высота блока зависит от текста.
- `/kzg` открывает настройки. Каждый тип целей можно включить отдельно; настройки общие для аккаунта на сервере.
- Eidetic Memory и кодекс древностей не отслеживаются.

## Категории и источники прогресса

Сеты, рыбалка (по числу рыб), встречи (включая М’Айка), музеи, коллекционные награды, древности с полезными наградами,
особые достижения, публичные подземелья, побочные задания, достижения ежедневных заданий,
мотивы и местные части общих достижений.

Счётчик категории показывает количество выполненных **целей**, а строка цели — её собственные критерии.
Отключённые категории не входят в итог. Скрытые выполненные цели входят.
Общие достижения с местными критериями учитываются только по критериям выбранной области.
Большинство достижений и коллекций общие для аккаунта; задания проверяются для текущего персонажа.

## Ограничения покрытия

Это каталог дополнительных целей из перечисленных в SOURCES.md источников, а не гарантия полного прохождения игры.
Статические связи достижений с областями требуют обновления при выходе нового контента.
Динамические события пока добавляются **вручную по ID или ссылке на достижение** через настройки:
автоматические связи событий с областями в эту версию не включены. Их категория имеет отдельный переключатель.
Каталог мотивов пока охватывает 25 проверенных связей; изучение глав читается из достижения, наличие страницы в сумке не считается изучением.
Древности сгруппированы по области раскопки. Место получения зацепки указано отдельно и может находиться в другой области. Источники берутся из установленного Lead List; некоторые новые записи в его русской локализации пока на английском.
Обычная мебель без постоянного коллекционного открытия автоматически не отслеживается.
Недоступные задания (удалённые, закрытые сюжетным выбором или дальнейшим прохождением) определяются по LibQuestData, показаны красным со значком запрета и не входят в счётчик. Выполненные и активные задания имеют приоритет над этим фильтром. Невыполненные предварительные условия сами по себе не исключают задание. Неизвестные библиотеке случаи можно исключить правым кликом.
Режим геймпада пока не поддерживается.

## Установка

Папка `KanaZoneGoals` должна находиться в `live/AddOns`. Обязательны **LibAddonMenu-2.0, LibSets, LibMapData, LeadList**.
Для рыбалки нужен **RareFishTracker**, для побочных заданий — **LibQuestData**.
Включите аддон в списке модификаций. Если новая папка не появилась после `/reloadui`, вернитесь к выбору персонажа.

## Проверка и обновление данных

Из корня аддона: `for test in tests/test_*.lua; do lua "$test" || exit 1; done`.
Тесты проверяют модель, API-провайдеры на фикстурах, настройки и добавление строк в модель штатного списка.
Они не заменяют проверку отрисовки и загрузки в клиенте ESO.

`tools/import_mappins.lua` извлекает связи из MapPins, USPF и Zone Dailies Achievement Tracker.
Пути задаются аргументами; исходные аддоны нужны только при обновлении каталога.
Код их приложений не запускается. Координаты, тексты заданий и прогресс не копируются.

Правый клик по подсказке или строке передаётся штатной карте. Выбор категорий доступен в `/kzg`.

Задания с типом `QUEST_TYPE_DUNGEON` исключены из побочных заданий областей, даже если игра относит подземелье к родительской области.
